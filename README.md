# LED Brightness Adjusting Project

## 1. Aim

To design and build a simple **LED brightness control circuit** using a potentiometer, LED, resistor, and power supply, allowing the brightness of the LED to be adjusted manually.

## 2. Problem Statement

In many basic electronic applications, it is necessary to control the brightness of an LED according to the user's requirement. A fixed resistor provides a constant current and does not allow the LED brightness to be adjusted easily.

To solve this problem, a **potentiometer** is used as a variable resistance to control the current flowing through the LED and adjust its brightness.

## 3. Proposed Solution

The proposed system uses a **potentiometer to adjust the current supplied to an LED**.

By rotating the potentiometer, the resistance in the circuit changes. This changes the current flowing through the LED, causing its brightness to increase or decrease.

The circuit provides a simple and low-cost method for demonstrating the basic concepts of **variable resistance, current control, and LED operation**.

## 5. Circuit Working

The LED is connected to the power supply through a resistor and potentiometer.

The resistor is used to limit the current flowing through the LED and protect it from excessive current. The potentiometer provides variable resistance in the circuit.

When the potentiometer is rotated:

* **Increasing the resistance** reduces the current flowing through the LED.
* Reduced current causes the **LED brightness to decrease**.
* **Decreasing the resistance** increases the current flowing through the LED.
* Increased current causes the **LED brightness to increase**.

Therefore, the LED brightness can be manually adjusted by rotating the potentiometer.

## 6. Procedure

1. Connect the components to the breadboard according to the circuit diagram.
2. Connect the positive terminal of the power supply to the circuit.
3. Connect the LED with the correct polarity.
4. Connect the resistor in series with the LED to limit the current.
5. Connect the potentiometer to control the resistance/current.
6. Connect the circuit ground to the negative terminal of the power supply.
7. Check all connections carefully before powering the circuit.
8. Switch ON the power supply.
9. Rotate the potentiometer slowly in both directions.
10. Observe the change in LED brightness.
